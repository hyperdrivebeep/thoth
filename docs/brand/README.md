# THOTH brand starter

## Idea

**Evidence. Judgment. Revision.** / **근거를 따라, 판단의 변화를 남기다.**

The three connected points in the mark form a `T`. They stand for source evidence, a research judgment, and the next recorded revision. The mark does not imply that an AI result is certified or final.

## Assets

- [`thoth-mark.svg`](thoth-mark.svg): square symbol for small surfaces.
- [`thoth-lockup.svg`](thoth-lockup.svg): dark horizontal lockup for README and presentations.
- [`thoth-ibis-hero.png`](thoth-ibis-hero.png): original ibis-headed Thoth illustration for a brand or README hero. Keep it as artwork rather than shrinking it into a small icon.
- [`thoth-readme-banner.svg`](thoth-readme-banner.svg): wide GitHub header using the original mark geometry, wordmark and brand colors.

Keep the symbol's proportions and clear space. On a small surface, use the mark without the tagline. Do not use status colors as a scientific confidence scale.

## Colors

These colors follow the existing Web workbench palette. They are a brand starting point, not a claim that the entire UI has been migrated to one token system.

## Voice

Describe what a reviewer can inspect: the question, evidence, competing explanations, unresolved points, next actions, and revisions. Say **partial**, **on hold**, or **not yet tested** where appropriate. Avoid claims of proven research quality, time saved, institutional approval, or field impact until those claims have independent evidence.

### Short description

THOTH is an AI-assisted R&D workbench that connects research questions to source evidence, competing hypotheses, next actions, and a reviewable history of changes.

### Korean description

THOTH는 연구 질문부터 원문 근거, 경쟁 가설, 다음 행동, 변경 이력까지 한 흐름에서 살펴보는 AI 연구 워크벤치입니다. 근거가 모자라면 결론을 확정하지 않고 미해결 상태로 남깁니다.
