THOTH is a local AI-assisted research workbench. Start with a question and source documents, follow the answer back to evidence, compare possible explanations and keep a history of revised judgments.

This is the first **beta**. It follows [v0.1.0-preview](https://github.com/hyperdrivebeep/thoth/releases/tag/v0.1.0-preview) and is meant for people who will try the product and report what breaks or confuses them. It is not a claim of validated research quality. Testers: start with the [beta guide](https://github.com/hyperdrivebeep/thoth/blob/main/docs/BETA.md).

## What changed for you

- **Delete an archived project permanently (#55).** Archive a project, open *View archived projects*, choose *Delete permanently* and type the project name. The project's conversations, source records and uploaded original files are removed; files shared with another project stay. Deletion is refused while work in the project is running and in the hosted review environment. It cannot be undone.
- **Language choices moved into Settings (#50).** Display language and response language are set in a Settings card. A request keeps the language it was sent with, including through retries and recovery, and the next question can use another one.
- **Research answers are easier to check.** Progress shows source positions instead of quoted text (#30). Cited evidence keeps its document structure and reviewers are told what they saw (#32). Step ratios and slopes of repeated measurement rows are calculated rather than guessed (#34), claims that something is absent are checked against the source text (#35), earlier model interpretations are labelled and reviewers cite calculated ratios (#36), and the review task wording was repaired (#33).
- **More reliable background work.** Windows process-tree cleanup is confirmed only after the whole job is gone (#31) and evaluation workers end their whole process tree (#46). Test timing no longer depends on machine load (#45), and the Windows user lookup for profile permissions happens once per process (#47).
- **Small interface fixes.** The sidebar project menu stays visible outside the scrolling list, selected text no longer runs under a dropdown's arrow, and conversation titles use the body font.

## Experimental, off by default

- **Local retrieval preparation** (Settings → *Local retrieval preparation*, #52, #51). Optionally download or import an embedding model (about 124 MB per workspace) and build a local index. It needs the extra install `--extra local-retrieval` (about 110 MB) and does not change the active search policy. Model downloads are accepted from huggingface.co and its subdomains, the install guide explains the optional parts, and passages longer than 512 tokens are embedded from their first 512 tokens so a very long page cannot exhaust memory.
- **Retrieval experiments (#37–#42, #48, #49).** Candidate selection moved into one domain function, with protected-identifier, grouped keyword, Korean bigram and Korean-to-English glossary lanes and a document-count switching rule, all evaluated in shadow only. The switching rule failed its held-out test (see below), so none of them is the default.

## Install and upgrade

This release is `v0.2.0-beta.1`; `thoth.cli version` reports it as `0.2.0b1` (Python's spelling of the same version). Use a **Windows source checkout, Python 3.12 or 3.13, uv, Node.js and pnpm** as before. Follow the [installation guide](https://github.com/hyperdrivebeep/thoth/blob/main/docs/INSTALL.md) and rerun the locked install: `markdown-it-py` is now a required dependency.

**Back up your workspace before opening it with the beta.** Opening an existing workspace applies two migrations automatically: `5d28a619afb4` (local retrieval index tables) and `8e3b5f1a7c42` (record of permanently deleted projects). Both only add tables. THOTH has no downgrade command, so keep the backup if you want to return to the preview.

Model use costs your account's allowance or provider charges. Recorded synthetic examples used about **8–9 calls and 330,000–450,000 tokens per investigation**, mostly input. See [usage and cost](https://github.com/hyperdrivebeep/thoth/blob/main/docs/INSTALL.md#model-usage-and-cost).

## Known limits

- The experimental search rule was tested on 30 held-out cases and **failed** its promotion criteria: it improved evidence recall when many documents were mixed, but not inside one project's own documents, and its per-query time was too high. It stays off by default.
- Permanently deleting a project keeps files that other projects share; there is no cleanup tool for unused files yet, and a leftover "running" record from an abnormal shutdown can block deletion.
- On Korean Windows a backslash can show as ₩ in some code boxes, and the text under the model chooser can be clipped.
- Windows source checkout only. Claude and xAI real-account sign-in is unverified, and the ChatGPT/Codex bridge is experimental.
- Real-model runs used synthetic material. They show that investigations run and save results, not that answers are correct or useful on your data.

Read the [verification record](https://github.com/hyperdrivebeep/thoth/blob/main/docs/VERIFICATION.md), [known limitations](https://github.com/hyperdrivebeep/thoth/blob/main/docs/KNOWN_LIMITATIONS.md) and the [security policy](https://github.com/hyperdrivebeep/thoth/blob/main/SECURITY.md). Report problems with a **Beta feedback** issue; for sensitive reports use **Security → Report a vulnerability**.
