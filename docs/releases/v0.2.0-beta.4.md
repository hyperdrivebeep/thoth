THOTH is a local AI-assisted research workbench. Start with a question and source documents, follow the answer back to evidence, compare possible explanations and keep a history of revised judgments.

This release gathers the fixes from a full audit of [v0.2.0-beta.3](https://github.com/hyperdrivebeep/thoth/releases/tag/v0.2.0-beta.3): screens, wording, accessibility, narrow windows and the local request boundary. If you are testing a beta, please update. Testers: start with the [beta guide](https://github.com/hyperdrivebeep/thoth/blob/main/docs/BETA.md).

## What changed for you

**Conversations**

- The answer stays in view. The question area takes about a fifth of the window, a conversation opens at its latest answer, and a finished answer opens by itself (#74, #78).
- A turn that is still being researched shows only its question while the progress block below it reports what is happening. Before, it could look like a turn with no answer (#78).
- The progress block names each place and sentence once (#78).
- Earlier rounds open their evidence again, and no longer claim "no usage recorded" or "checks not read yet" when the server simply does not send those for earlier rounds (#77, #78).
- Open follow-ups that were shown as English "Resolve ..." sentences now appear in the screen language or in your own words (#78).
- Projects and conversations can be renamed. A source can be detached after a warning that existing answers will need review (#74).

**Sources and settings**

- The Sources tab lists connected sources first. The usage scope is already set to "Shared within this project", so choosing files and pressing **Connect** is all it takes; files that cannot be uploaded are explained before sending (#75).
- Project settings and computer settings are two separate screens. With no model connected, settings show one sentence and a link (#75).
- The help for source scope now says plainly that there is no screen yet for granting a single task permission: whichever scope you choose, research in the project can read the source (#78).

**Reading and accessibility**

- No text is smaller than 12 px (#76).
- The same unit is called a conversation in every language (#76).
- At 320 and 390 px no screen scrolls sideways; at 760 px and below the project list becomes a drawer (#75).
- Closing a dialog returns keyboard focus to where it was (#78). axe reports no violations on 17 screens.

**Safety and diagnosis**

- Unexpected failures are written to `<workspace>/logs/thoth.log` with an operation id that the screen also shows. Request text and token-shaped values are left out (#74).
- The API key file is written atomically, is not overwritten when it cannot be read, and on Windows is readable only by the current user (#74).
- Changing requests are accepted only from THOTH's own address and the development address on port 5173. Local responses refuse framing (#74).

## Known limits

- When you stop research yourself, the record does not yet say why it stopped, so the screen says the reason could not be confirmed.
- "Explicitly permitted tasks only" does not restrict anything yet; see the source scope help above.
- Japanese and Chinese wording has not had a native-speaker review. Reports are welcome.

## Install and upgrade

This release is `v0.2.0-beta.4`; `thoth.cli version` reports it as `0.2.0b4`. Follow the [installation guide](https://github.com/hyperdrivebeep/thoth/blob/main/docs/INSTALL.md). There is no new migration: a beta.3 workspace opens without changes. Everything else in the [v0.2.0-beta.2 notes](https://github.com/hyperdrivebeep/thoth/releases/tag/v0.2.0-beta.2), including the known limits, still applies.

Report problems with a **Beta feedback** issue; for sensitive reports use **Security → Report a vulnerability**.
