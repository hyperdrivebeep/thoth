# v0.1.0-preview — release notes

Published on 2026-10-25 as a GitHub pre-release: [v0.1.0-preview](https://github.com/hyperdrivebeep/thoth/releases/tag/v0.1.0-preview).
Release commit: `24f96279ab6c94789d342f5035cc9a548a7de922`.

THOTH is a local AI-assisted research workbench. Start with a question and source documents, follow the answer back to evidence, compare possible explanations and keep a history of revised judgments.

This is the first public **preview** release. It is not a claim of validated research quality.

## What you can inspect

- Questions, source-located evidence, competing hypotheses, discriminating tests and expected results. Expected-result rows distinguish a restated observation, an inference from data and a hypothetical prediction. AI proposals remain subject to review; an evidence link does not validate causality.
- A trace table linking requirements, criteria and recorded results. Rules compute assessments; model answers do not replace the recorded criterion.
- Project memory, saved answers and comparisons between exact revisions. Supported restores create a new revision, and queued input retains request identity through recovery.
- Separate Korean/English display and response-language choices. An accepted request keeps its language through retries and recovery; a later question can select another language.

## Install and budget for use

Use a **Windows source checkout, Python 3.12 or 3.13, uv, Node.js and pnpm**. Keep the migration tree and locked dependency files with the source; this preview does not support installation as a standalone wheel. Follow the [installation guide](https://github.com/hyperdrivebeep/thoth/blob/v0.1.0-preview/docs/INSTALL.md) and protect the selected workspace when backing up.

Recorded synthetic examples used about **8–9 calls and 330,000–450,000 tokens per investigation**, mostly input. Actual use depends on the material and the investigation. Sign-in uses the account's subscription allowance; API keys incur provider charges. Read the [usage and cost guidance](https://github.com/hyperdrivebeep/thoth/blob/v0.1.0-preview/docs/INSTALL.md#model-usage-and-cost).

## Verification and limits

This release is commit 24f9627 on `main`. Its [CI run](https://github.com/hyperdrivebeep/thoth/actions/runs/40172873404) finished with 5,828 Python tests passed, zero failures or errors and two skipped cases; the other CI checks also passed.

Real-model synthetic runs demonstrate execution and saved results, not scientific validity or usefulness on real data. The English captures show an English question, answer and source text; the recorded run used an explicit English response choice. For new trace-row questions, an explicit reply-language choice takes precedence; otherwise the question follows the display language. Broader language quality is not established, and display settings do not translate source documents. Real-account coverage, physical PC restart coverage and timing-sensitive tests also have limits.

Read the [verification record](https://github.com/hyperdrivebeep/thoth/blob/v0.1.0-preview/docs/VERIFICATION.md), [known limitations](https://github.com/hyperdrivebeep/thoth/blob/v0.1.0-preview/docs/KNOWN_LIMITATIONS.md) and the [security policy](https://github.com/hyperdrivebeep/thoth/blob/v0.1.0-preview/SECURITY.md). For sensitive reports, use **Security → Report a vulnerability** on this repository.
