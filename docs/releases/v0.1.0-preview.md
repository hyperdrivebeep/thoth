# v0.1.0-preview — draft release notes

**Unpublished draft.** The tag and GitHub release have not been created. Before publication, confirm
the exact release revision and its checks, and review the security policy.

THOTH is a local AI-assisted research workbench. Start with a question and source documents, follow
the answer back to evidence, compare possible explanations and keep a history of revised judgments.
This is the first planned public preview release, not a claim of validated research quality.

## What you can inspect

- Questions, source-located evidence, competing hypotheses, discriminating tests and expected results.
  Expected-result rows distinguish a restated observation, an inference from data and a hypothetical
  prediction. AI proposals remain subject to review; an evidence link does not validate causality.
- A trace table linking requirements, criteria and recorded results. Rules compute assessments;
  model answers do not replace the recorded criterion.
- Project memory, saved answers and comparisons between exact revisions. Supported restores create
  a new revision, and queued input retains request identity through recovery.
- Separate Korean/English display and response-language choices. An accepted request keeps its
  language through retries and recovery; a later question can select another language.

## Install and budget for use

Use a **Windows source checkout, Python 3.12 or 3.13, uv, Node.js and pnpm**. Keep the migration tree and
locked dependency files with the source; this preview does not support installation as a standalone wheel.
Follow the [installation guide](../INSTALL.md) and protect the selected workspace when backing up.

Recorded synthetic examples used about **8–9 calls and 330,000–450,000 tokens per investigation**,
mostly input. Actual use depends on the material and the investigation. Sign-in uses the account's
subscription allowance; API keys incur provider charges. Read the [usage and cost guidance](../INSTALL.md#model-usage-and-cost).

## Verification and limits

The [reviewed PR #25 CI run](https://github.com/hyperdrivebeep/thoth/actions/runs/40156740267) finished with
5,828 Python tests passed, zero failures/errors and two skipped cases on the first run attempt.
This is evidence for that revision, not a release check for an unspecified later commit.
The final release revision still needs its own recorded decision.

Real-model synthetic runs demonstrate execution and saved results, not scientific validity or
usefulness on real data. The English captures show an English question, answer and source text;
the recorded run used an explicit English response choice. For new trace-row questions, an explicit
reply-language choice takes precedence; otherwise the question text follows the display language.
Broader language quality is not established, and display settings do not translate source documents.
Real-account coverage, physical PC restart coverage and timing-sensitive tests also have limits.

Read [verification and its historical records](../VERIFICATION.md), [known limitations](../KNOWN_LIMITATIONS.md)
and the [draft security policy](../../SECURITY.md). Private vulnerability reporting is enabled;
use the repository's **Security → Report a vulnerability** action for sensitive reports.
