THOTH is a local AI-assisted research workbench. Start with a question and source documents, follow the answer back to evidence, compare possible explanations and keep a history of revised judgments.

This is a **fix release** for [v0.2.0-beta.2](https://github.com/hyperdrivebeep/thoth/releases/tag/v0.2.0-beta.2). If you are testing a beta, please update. Testers: start with the [beta guide](https://github.com/hyperdrivebeep/thoth/blob/main/docs/BETA.md).

## What changed for you

- **The evidence panel opens again (#73).** In v0.2.0-beta.1 and v0.2.0-beta.2, opening the evidence of a research answer showed "This answer's evidence could not be read" for every result made from 27 October 2026, and for some results saved in the older format before 24 October. The evidence itself was stored correctly; the screen compared the short summary it displays with the stored record and rejected the difference. The server now also returns the exact result as the screen shows it, and the screen checks against that, with the same strictness for everything else. No stored record is changed.

## Install and upgrade

This release is `v0.2.0-beta.3`; `thoth.cli version` reports it as `0.2.0b3`. Follow the [installation guide](https://github.com/hyperdrivebeep/thoth/blob/main/docs/INSTALL.md). There is no new migration: a beta.2 workspace opens without changes. Everything else in the [v0.2.0-beta.2 notes](https://github.com/hyperdrivebeep/thoth/releases/tag/v0.2.0-beta.2), including the known limits, still applies.

Report problems with a **Beta feedback** issue; for sensitive reports use **Security → Report a vulnerability**.
