THOTH is a local AI-assisted research workbench. Start with a question and source documents, follow the answer back to evidence, compare possible explanations and keep a history of revised judgments.

This is the second **beta**. It follows [v0.2.0-beta.1](https://github.com/hyperdrivebeep/thoth/releases/tag/v0.2.0-beta.1) and is meant for people who will try the product and report what breaks or confuses them. It is not a claim of validated research quality. Testers: start with the [beta guide](https://github.com/hyperdrivebeep/thoth/blob/main/docs/BETA.md).

## What changed for you

- **Meaning-based search is on for every project once it is installed (#70, #71, #72).** After you install the optional local retrieval parts and the embedding model in Settings, every project builds its index in the background and research also looks for passages with similar meaning, not only the same words. Until a project's index is ready, or when the parts are not installed, research uses the existing keyword search. You can still turn it off for a project in Settings; projects you turned off stay off.
- **Japanese and Chinese (#60, #61, #68).** Answers and the screen are available in Japanese, Simplified Chinese and Traditional Chinese. Traditional Chinese is machine-converted and has not been reviewed by a native speaker yet.
- **Easier to read results (#62, #63, #64, #65).** The result card leads with its status tags, earlier turns of a conversation fold into one line each, the project page shows whether sources are ready first, and an investigation that stopped after its answer was saved says so.
- **Safer changes and files (#59, #61).** Changes to an investigation are applied all at once or not at all, older Chinese, Japanese and Korean text encodings are read without silently corrupting text, a source that cannot be read says why, unused shared files can be pruned and work left running by a crash is closed.
- **Faster first question on large projects (#71).** Preparing the meaning-search data no longer blocks the server, so the first question after a restart is not held up.

## Install and upgrade

This release is `v0.2.0-beta.2`; `thoth.cli version` reports it as `0.2.0b2`. Use a **Windows source checkout, Python 3.12 or 3.13, uv, Node.js and pnpm** as before and follow the [installation guide](https://github.com/hyperdrivebeep/thoth/blob/main/docs/INSTALL.md). Meaning-based search needs the optional install `--extra local-retrieval` (about 110 MB) and the embedding model (about 124 MB per workspace), added from Settings.

**Back up your workspace before opening it with this beta.** Opening a beta.1 workspace applies one migration automatically, `9f4c2d7e1a35`, which only adds two columns to the local index table. Coming straight from the preview applies three (`5d28a619afb4`, `8e3b5f1a7c42`, `9f4c2d7e1a35`). There is no downgrade command. Existing local indexes are rebuilt once because the passage preprocessing version changed (the model does not need to be reinstalled). Research records saved by this version use record format 2.4.0 and cannot be read by beta.1.

Model use costs your account's allowance or provider charges. See [usage and cost](https://github.com/hyperdrivebeep/thoth/blob/main/docs/INSTALL.md#model-usage-and-cost).

## Known limits

- **Meaning-based search did not pass its new held-out evaluation and is on by product decision.** On 64 new cases it found more of the right passages and fewer wrong ones than keyword search in all four tested conditions, but two preregistered criteria failed: memory grew by about 650 MB on a project of about 20,000 passages (limit 600 MB), and in one condition the recall gain was +2.8 points against a +3.0 threshold. A new evaluation with a new case set is planned.
- The first index of a large project takes a while (about 9 minutes for 20,000 passages on the test machine) and uses CPU in the background. Up to two projects keep their search data in memory; switching between three or more large projects rebuilds it, and the question asked during that rebuild uses keyword search.
- Automatic indexing starts with the first request after the server starts. A source whose indexing failed is not retried automatically; use *Retry* in Settings. A project whose local retrieval setting was last changed from a signed-in session is skipped by automatic indexing; use *Prepare index* in Settings for it.
- Traditional Chinese text is machine-converted. On Korean Windows a backslash can show as ₩ in some code boxes.
- Windows source checkout only. Claude and xAI real-account sign-in is unverified, and the ChatGPT/Codex bridge is experimental.
- Real-model runs used synthetic material. They show that investigations run and save results, not that answers are correct or useful on your data.

Read the [verification record](https://github.com/hyperdrivebeep/thoth/blob/main/docs/VERIFICATION.md), [known limitations](https://github.com/hyperdrivebeep/thoth/blob/main/docs/KNOWN_LIMITATIONS.md) and the [security policy](https://github.com/hyperdrivebeep/thoth/blob/main/SECURITY.md). Report problems with a **Beta feedback** issue; for sensitive reports use **Security → Report a vulnerability**.
